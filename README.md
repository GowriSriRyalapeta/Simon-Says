# Simon Says

A browser-based memory game built with HTML, CSS, and JavaScript. The game generates a sequence of colors that the player must reproduce correctly, with the sequence becoming progressively longer as the level increases.

# How to play your Simon Says game
Open the game on a laptop using a web browser.
The game has four colored buttons arranged in a square.
Press any key on the keyboard to start the game.
The game will light up one colored button as the first sequence.
Click the button that just lit up.
After a correct click, the game adds another color to the sequence.
You must remember the entire sequence from the beginning and click the colors in the same order.
With every successful round, the sequence becomes longer, making the game progressively harder.
If you click the wrong button, the game ends and displays the game-over state.
Press a key again to restart and play a new sequence.

## Tech Stack

**HTML5** — Page structure and game interface  
**CSS3** — Styling, layout, animations, and visual effects  
**JavaScript** — Game logic, sequence generation, event handling, and state management

# Simon Says

A browser-based memory game built with HTML, CSS, and JavaScript. The game generates a sequence of colors that the player must reproduce correctly, with the sequence becoming progressively longer as the level increases.

## Features

- Sequence-based memory gameplay
- Progressive difficulty with level tracking
- Interactive button animations and visual feedback
- Keyboard-based game initialization
- Game-over handling for incorrect sequences
- Responsive user interface

## Tech Stack

**HTML5** — Page structure and game interface  
**CSS3** — Styling, layout, animations, and visual effects  
**JavaScript** — Game logic, sequence generation, event handling, and state management
